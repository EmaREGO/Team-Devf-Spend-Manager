# Gestor de Finanzas Personales (Wallet App)

Una aplicación web Full Stack diseñada para ayudar a los usuarios a llevar un control preciso de su dinero. Permite registrar ingresos y gastos, establecer presupuestos y visualizar el balance en tiempo real a través de una interfaz moderna y segura.

Este proyecto es el resultado final del programa de Frontend de DEVF, desarrollado de manera incremental implementando protección de rutas, manejo de validaciones, optimización de renderizado y despliegue continuo (CI/CD) en Vercel.

## 🎯 Objetivo
Crear una aplicación Front-End escalable que aplique conceptos avanzados de React (Hooks, Context, optimización) y demuestre un flujo de trabajo colaborativo profesional mediante Git y GitHub.

## 🚀 Funcionalidades
- **Seguridad y Autenticación:** Protección de datos mediante rutas privadas y redirección al login.
- **Gestión de movimientos (CRUD):** Registro, edición y eliminación de ingresos y gastos.
- **Balance en tiempo real:** Actualización instantánea del balance.
- **Manejo de errores:** Formularios protegidos con Zod para prevenir montos negativos o datos incompletos.
- **Gestión de presupuestos:** Definición de límites de gasto por periodo.

## 🛠 Stack Tecnológico
- **Frontend:** React (Vite), JavaScript, CSS/Tailwind (por definir).
- **Validaciones:** Zod.
- **Backend/Datos:** LocalStorage / Mock API (Sujeto a definición).
- **Despliegue:** Vercel.
