# Gestor de Finanzas Personales (Wallet App)

## Descripción del Proyecto
Una aplicación web Full Stack diseñada para ayudar a los usuarios a llevar un control preciso de su dinero. Permite registrar ingresos y gastos, establecer presupuestos y visualizar el balance en tiempo real a través de una interfaz moderna y segura.

Este proyecto fue desarrollado bajo metodologías ágiles, implementando una arquitectura Full Stack, protección de rutas, manejo estricto de validaciones y despliegue continuo (CI/CD).

## Características Principales
*   **Seguridad y Autenticación:** Creación de cuentas y protección de datos mediante rutas privadas. Redirección automática si no hay sesión activa.
*   **Gestión de Movimientos (CRUD):** Registro, edición y eliminación de ingresos y gastos con actualización matemática instantánea del balance.
*   **Manejo de Errores:** Formularios blindados que previenen el envío de montos negativos o datos incompletos, devolviendo retroalimentación visual clara al usuario.
*   **Recordatorios y Presupuestos:** Marcado de pagos recurrentes con alertas visuales en el panel principal para evitar recargos.
*   **Despliegue Continuo:** Integración con Vercel para despliegues automáticos (CI/CD) tras cada actualización en la rama principal.
